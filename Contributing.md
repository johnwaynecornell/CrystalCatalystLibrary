## Commit Message Guidelines

We use a standardized commit message format to ensure clarity and consistency. Please follow the format below for all commit messages:


### Examples:

- **ProcessHandler** **Establish** - mechanism for invoking shell
- **UI** **Update** - enhance button styling
- **Database** **Fix** - resolve connection timeout issue

### Components:
- Use the main component or module affected by the change.

### Actions:
- Use an imperative verb to describe the action (e.g., Establish, Update, Fix, Remove).

### Description:
- Provide a brief description of the change.

This format helps maintain a clear and understandable project history.
